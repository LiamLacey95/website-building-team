Stack

  • Astro 7, static. No client framework; one vanilla JS module capped at 10 KB gzipped.
  • The repo is the CMS. A build-time pipeline reads briefs, research, concept images and sidecars, screenshots, gate packets, review verdicts and the git log.
  • Guardrails in the build: quotes taken from real files by marker (the build fails if a source vanishes), non-commercial images refused, output scanned for private details, other companies' screenshots never published.
  • GitHub Pages via Actions, $0, base path /website-building-team.
  • Gate 4 enforced by GitHub: deploy waits for your approval.
  • Signed off by Front-end, "OK with notes", notes folded in.
