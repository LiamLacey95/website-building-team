## bootstrap.mjs

Node 20+, no npm dependencies. It's interactive by default. Every prompt has a flag, plus `--yes`, which is implied when stdin is not a terminal (as in agent shells). There are also `--dry-run`, `--check`, `--selftest`, `--reinstall` and `--help`. Each step checks before it acts, so re-runs are safe and a failed run can simply be repeated.

1. **Prerequisites:** git, Node, npm, Python 3.11 to 3.13 (3.13 preferred; the Windows Store stub is skipped), `gh` and its sign-in, NVIDIA GPU and VRAM, and free disk space (40 GB on the target when installing ComfyUI). Each item that fails comes with guidance. Bootstrap stops only if git or npm is missing.
2. **Config:** values come from the flag first, then the existing config, then the prompt, then the default.
3. **Node tooling:** `npm ci` in `tools/` and `docs/review/tools/` (skipped while `node_modules/.package-lock.json` is newer than the package files), then Playwright Chromium if it's missing (`--with-deps` is opt-in on Linux).
4. **Impeccable**, as specified by Front-end and the PM:
   - The skills are committed, so normally nothing is installed. If they're missing, or with `--reinstall`, bootstrap runs `npx --yes impeccable@<pin> install --scope=project --providers=… --no-hooks -y` (adding `--force` only on reinstall). The pin is read from `tools/package.json`.
   - It then warms the engine with the committed launcher and runs `impeccable telemetry off`, which is persistent per machine.
   - `IMPECCABLE_NO_TELEMETRY=1` is set for every child process.
   - Bootstrap never runs `hooks on` or `doctor --fix`.
5. **ComfyUI**, following Concept's interface in `artgen/setup/README.md`:
   - **Connect:** runs `install_comfyui.py --verify` (exit 0 green, 3 amber, 1 red). On amber or red, interactive mode offers `--models-only`. With `--yes`, missing models are fetched automatically when the download is 2 GB or less; a fresh clone needs this for RealESRGAN, which is 67 MB and ungated. Bootstrap re-verifies afterwards, so a red result that wasn't about models stays red.
   - **Install into a folder that already has ComfyUI:** bootstrap stops and tells you to use `--comfyui-path` instead.
   - **Install** and **models-only:** run `--dry-run --json` first, which reports sizes, disk, GPU, torch, token and blockers, and stop if anything is blocked. After confirmation they run `--yes --json`, and `comfyui.python` is taken from the result.
   - **Configure:** `configure.py` runs after the config is on disk.
6. **Worktrees folder:** created if missing.
7. **Health check:** green, amber or red per item. The ComfyUI items come from `--verify --quick --json` and `configure.py --check --json`, and telemetry status is read from the machine setting. `--check` exits 1 if anything is red.

`--selftest` runs `tools/selftest.mjs`, `docs/review/tools/selftest.mjs` and `generate.py --smoke`. `--smoke` runs only the ComfyUI smoke test, which Concept asked for.
