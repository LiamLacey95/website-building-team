# G2 Creative direction: review checklist

Inputs: `design/concepts/<direction>/` for each of the 3 directions (moodboard, palette, type pairing, key art, style tile), plus the G1 decision in `.team/DECISIONS.md`.
Report: `docs/review/<brief id>-g2.md`.

## Distinctness and fit
- [ ] There are 3 directions, and they differ in at least two of palette, typography, imagery style and layout attitude. Two near-identical directions is a MAJOR finding.
- [ ] Each direction states its idea in one line and says which persona and positioning it serves.
- [ ] Each fits the audience and tone from G1 and does not contradict the brief's constraints.

## Colour and contrast (compute, do not eyeball)
- [ ] Run `node docs/review/tools/contrast.mjs --palette <palette.json>` for each direction and attach the output.
- [ ] Every intended text/background pair passes AA: 4.5:1 normal text, 3:1 large text (24 px, or 18.66 px bold).
- [ ] UI component and focus indicator colours reach 3:1 against adjacent colours (WCAG 1.4.11, 2.4.13).
- [ ] Meaning is never carried by colour alone (status messages, and links in body text are underlined or otherwise distinct).
- [ ] Any failing pair is either dropped from text use or flagged with a compliant alternative.

## Typography and licensing
- [ ] Each font is named with its licence (OFL, commercial with a web licence, and so on) and source URL. An unlicensed or unverifiable font is a BLOCKER.
- [ ] Body size is at least 16 px with a line height of about 1.4 to 1.6. The type scale is defined.
- [ ] The fonts cover the needed character set and weights; the total webfont weight is estimated (target under 100 KB for the critical fonts).

## Generated imagery (inspect each image at 100%)
- [ ] No anatomical artefacts: hands and fingers, eyes, teeth, limbs, merged objects.
- [ ] No fake or garbled text, pseudo-letters, watermarks or signatures.
- [ ] No brand lookalikes (logos, trade dress, recognisable characters) and no real identifiable people.
- [ ] No obvious seams, tiling, smears or melted geometry; lighting and perspective are consistent.
- [ ] Prompt, seed, model and workflow are recorded next to each image (playbook rule). A missing record is MAJOR.
- [ ] Images work at the crop ratios needed (hero 16:9 and 4:5 mobile) without losing the subject.
- [ ] Representation and tone are appropriate for the audience, with no stereotypes.

## Style tile
- [ ] It shows the type scale, colour roles (not just swatches), buttons with default, hover and focus states, links, a form input and a card, so Front-end can build from it.
